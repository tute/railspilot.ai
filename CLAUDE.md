# RailsPilot.ai — Project Memory

## What is this

Marketing website for RailsPilot.ai. Static site: HTML, CSS, vanilla JS. Deployed via GitHub Pages with custom domain.

## Target audience

RailsPilot is for **any company that can benefit from automation** — not limited to software or engineering companies. Early clients came from software and engineering backgrounds, but the service applies broadly to any organization with repetitive processes that can be automated or augmented with AI.

The English landing page (`index.html`) currently focuses on Rails/software development services. The Spanish case studies (`case_studies/`) already showcase broader applications: construction site reports, budget cross-referencing for HR/insurance, and legal firms. This broader positioning is the intended direction.

## Structure

- `index.html` + `styles.css`: English landing page (Rails development service)
- `case_studies/`: Spanish-language case studies and hub page
  - `case_studies/index.html`: Hub: AI consulting for automation of repetitive work
  - `case_studies/**/`: Concrete examples
